# Setup — Java (Maven APT)

How to wire easy-query into a plain Java project. Proxy classes are generated by the annotation processor
(APT) at compile time. For Spring Boot use `setup-spring-boot.md`; for Kotlin use `setup-kotlin.md`.

## When to use / not

Use for a plain Java (non-Spring) project. The query/write/transaction DSL applies the same once
`EasyEntityQuery` is built.

## 1. Maven dependencies

```xml
<dependencies>
    <dependency>
        <groupId>com.easy-query</groupId>
        <artifactId>sql-core</artifactId>
        <version>3.1.89</version>
    </dependency>
    <dependency>
        <groupId>com.easy-query</groupId>
        <artifactId>sql-api-proxy</artifactId>   <!-- strong-typed proxy API -->
        <version>3.1.89</version>
    </dependency>
    <dependency>
        <groupId>com.easy-query</groupId>
        <artifactId>sql-mysql</artifactId>       <!-- dialect: pick one (sql-h2 / sql-pgsql / sql-mssql ...) -->
        <version>3.1.89</version>
    </dependency>
    <!-- APT processor: generates the *Proxy classes at compile time -->
    <dependency>
        <groupId>com.easy-query</groupId>
        <artifactId>sql-processor</artifactId>
        <version>3.1.89</version>
        <scope>provided</scope>
    </dependency>
    <!-- your JDBC driver + connection pool -->
    <dependency>
        <groupId>com.mysql</groupId>
        <artifactId>mysql-connector-j</artifactId>
        <version>9.2.0</version>
    </dependency>
    <dependency>
        <groupId>com.zaxxer</groupId>
        <artifactId>HikariCP</artifactId>
        <version>3.3.1</version>
    </dependency>
</dependencies>
```

The processor is auto-discovered via `META-INF/services` in the `sql-processor` jar — no explicit
`<annotationProcessorPaths>` is required, though you may add it if your build disables auto-discovery.
If you use Lombok, declare Lombok's processor too so both run.

## 2. Entity

```java
package com.test.entity;

import com.easy.query.core.annotation.Column;
import com.easy.query.core.annotation.EntityProxy;
import com.easy.query.core.annotation.Table;
import com.easy.query.core.proxy.ProxyEntityAvailable;
import com.test.entity.proxy.TopicProxy;   // generated by APT into <pkg>.proxy
import java.time.LocalDateTime;
import lombok.Data;

@Data
@Table("t_topic")
@EntityProxy
public class Topic implements ProxyEntityAvailable<Topic, TopicProxy> {
    @Column(primaryKey = true)
    private String id;
    private Integer stars;
    private String title;
    private LocalDateTime createTime;
}
```

The generated `TopicProxy` extends `AbstractProxyEntity` and exposes one typed accessor per column
(`id()`, `stars()`, `title()`, …). You never write it by hand.

## 3. Build EasyEntityQuery

```java
import com.easy.query.api.proxy.client.DefaultEasyEntityQuery;
import com.easy.query.api.proxy.client.EasyEntityQuery;
import com.easy.query.core.api.client.EasyQueryClient;
import com.easy.query.core.bootstrapper.EasyQueryBootstrapper;
import com.easy.query.core.logging.LogFactory;
import com.easy.query.mysql.config.MySQLDatabaseConfiguration;
import com.zaxxer.hikari.HikariDataSource;

HikariDataSource dataSource = new HikariDataSource();
dataSource.setJdbcUrl("jdbc:mysql://127.0.0.1:3306/mydb?serverTimezone=GMT%2B8&characterEncoding=utf-8&useSSL=false");
dataSource.setUsername("root");
dataSource.setPassword("root");
dataSource.setDriverClassName("com.mysql.cj.jdbc.Driver");
LogFactory.useStdOutLogging();

EasyQueryClient client = EasyQueryBootstrapper.defaultBuilderConfiguration()
        .setDefaultDataSource(dataSource)
        .useDatabaseConfigure(new MySQLDatabaseConfiguration())   // match the sql-* dialect artifact
        .build();
EasyEntityQuery easyEntityQuery = new DefaultEasyEntityQuery(client);

// ready to use:
List<Topic> list = easyEntityQuery.queryable(Topic.class)
        .where(o -> o.title().eq("hello"))
        .toList();
```

`useDatabaseConfigure(...)` must match the dialect artifact you depend on (e.g. `MySQLDatabaseConfiguration`
from `sql-mysql`, `H2DatabaseConfiguration` from `sql-h2`).

## Common mistakes

- Missing the `sql-processor` dependency → `*Proxy` classes never generated, compile fails. This is a build
  problem, not a code problem.
- Dialect mismatch: `useDatabaseConfigure(new MySQLDatabaseConfiguration())` while depending only on `sql-h2`.
- Forgetting `implements ProxyEntityAvailable<Entity, EntityProxy>` on the entity.
